# Android Internals, Bottom-Up

A book about how Android works on the inside: boot, kernel, native user space, Binder, ART, the framework, apps, and the security model.

The book is in progress. The outline is in [`src/SUMMARY.md`](src/SUMMARY.md).

## Read it locally

Install [mdBook](https://rust-lang.github.io/mdBook/), then run:

```sh
mdbook serve --open
```
